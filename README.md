## 🚀 Setup & Run

To run any project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/your-repo-name.git

# Navigate into a specific project
cd 03-inc-dec-proj

# Install dependencies
npm install

# Start the project
npm start
```
